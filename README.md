# Clockwork Sanctum

Sunlit isometric clockwork puzzle-chase in Three.js where you bounce golden sunbeams to shatter Stone Gargoyles, outsmart the stalking Shadow Rogue, and summon Mage's Astral Aid.

## How to Play
- **Move & Act**: Click any glowing golden node on the sunlit clockwork island to step your Knight, rotate mirrors, or crank brass gears.
- **Shatter Gargoyles**: Align mirrors and crystal prisms so golden sunbeams strike and shatter every Stone Gargoyle on the island.
- **Outsmart the Shadow Rogue**: After every move you make, the Shadow Rogue advances one tile along the board to hunt you down.
- **Astral Aid**: Summon the Mage's once-per-island Astral Aid to turn mirrors or crank gears from afar without spending a dangerous footstep.

## Local Development
```bash
npm install
npm run dev
```
